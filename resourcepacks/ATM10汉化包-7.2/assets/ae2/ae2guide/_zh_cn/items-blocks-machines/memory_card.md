# 内存卡

<ItemImage id="memory_card" scale="4" />

内存卡用于在 AE2 [ME设备](../ae2-mechanics/devices.md) 之间复制并粘贴设置，并连接
[P2P通道](p2p_tunnels.md)。它还可以将[升级卡](upgrade_cards.md) 粘贴到设备中。

- Shift+右键点击以复制设置，或生成新的 P2P链接频率。
- 右击以粘贴设置、升级卡或链接频率。
