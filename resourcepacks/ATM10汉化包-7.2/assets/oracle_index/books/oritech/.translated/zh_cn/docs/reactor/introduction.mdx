## 概览

奥瑞科技反应堆是大量发电的绝佳方式。
它消耗铀或钚燃料颗粒，并根据反应堆棒数量及邻近中子反射板数量产生RF。
但务必确保其充分冷却。

<center>
<ModAsset location="oritech:area/reactor" width={1000} />
</center>

反应堆内燃料燃烧产生热量，且有多种组件用于管理反应堆热量：
- 热量管道从燃料棒吸收热量，并沿管道传输。
- 反应堆散热口会从温度最高的邻近组件（如燃料棒或热管）中吸取部分热量，并将其排出反应堆外。
- 散热器可从所有相邻部件中吸收固定热量，但需持续供应冷却物品方可正常运作。

反应堆允许积聚一定热量。理想情况下，冷却良好的反应堆不会产生任何泄漏的热量。然而，部分组件（例如散热口）在更高温度的环境中效率更佳。若产生的热量过多且无法及时排出，燃料棒可能过热，进而引发核熔毁。若某根燃料棒持续处于超过2000℃的高温下，便会触发熔毁。  
反应堆温度达到危险阈值前，警报器将提前启动。熔毁所引发的爆炸规模，取决于反应堆尺寸及燃料棒数量，可能较大，也可能较小。

</Callout>

反应堆需由矩形墙体构成，其中边缘部分必须使用反应堆墙方块。反应堆在每个方向上的最大尺寸为64个方块。  
反应堆控制器需放置在墙体的任意位置，能量端口则可放置在侧墙面上。  
所有其他非端口组件均须置于反应堆内部。反应堆可采用任意高度建造，但其内部结构在垂直方向上必须保持一致。这意味着你只需在二维平面上设计反应堆，再按需沿垂直方向扩展即可。例如，内部高度为1时能正常运行的反应堆，其内部高度扩展至10后同样可以正常运行。不过，能量产出以及冷却液和燃料消耗量也会随之等比例缩放。
