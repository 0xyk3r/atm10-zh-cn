---
title: 流体处理插件
id: oritech:machine_fluid_addon
type: block
---

流体处理插件为原本仅支持物品处理的机器赋予流体处理能力。

它专用于以下运行：
- 要使[离心机](@oritech:centrifuge_block)进行处理并
分离流体。
- 用于[无人机港](@oritech:drone_port_block)运输流体。

<Callout variant="info">
    Once attached, the machine gains fluid storage and the corresponding
    fluid slots will be visible in the user interface.
</Callout>
