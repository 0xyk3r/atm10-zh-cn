Oracle索引还具备一项功能：内容需先解锁，玩家方可访问。锁定页面将以模糊方式呈现，且不会出现在搜索结果中。
若某文件夹下所有条目均被锁定，则整个文件夹将被隐藏。

<Callout variant="warning">
    This feature is obviously only available in the in-game wiki, not the online wiki. The main target audience here are modpack makers that don't want to reveal everything at once.
</Callout>

要控制解锁条件，页面的前置元数据需包含*unlock*部分。其格式如下所示：

```
---
title: Ingame Mod View Setup
unlock: advancement:minecraft:oritech/pulverizer
---
"unlock" is always the same
"advancement" is the name of the progress validator
anything after the "advancement:" part is passed to the validator
```

# 验证器
模组开发者可向**Oracle进度API**注册自定义验证器。更多详情请参阅该API类的Javadoc文档。

Oracle索引不会存储哪些条目已被解锁，而是按需调用验证器。

## 成就验证器
默认情况下，模组仅包含一个验证器：进度验证器。它会检查玩家是否已完成特定成就，以决定是否允许其查看页面。
