管道升压器是面向高吞吐量物流网络的升级组件。
将其紧邻管道抽取点放置并以RF供能后，可大幅提高从相连容器中抽取物品与流体的速度。

<center>
<ModAsset location="oritech:area/item_pipes_boosted" width={512} />
</center>

---

**抽取性能**

- **物品管道**: 将采集速率提升至每秒一整叠
每刻。
- **流体管道**: 将吞吐量提升至最高每刻 50 桶。

<Callout variant="info">
    A pipe booster must directly target an **extracting** pipe block 
    (the interface where the pipe meets the machine) to have any effect.
</Callout>
