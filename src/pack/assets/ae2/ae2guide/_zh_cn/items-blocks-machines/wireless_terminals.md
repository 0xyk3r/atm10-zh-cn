# 无线终端

<ItemImage id="wireless_terminal" scale="4" />


无线终端是普通有线[终端](terminals.md)的便携版本。它们的 UI 与
对应的有线版本完全相同，只不过用[升级卡](upgrade_cards.md)槽位取代了 <ItemLink id="view_cell" /> 槽位

要将它们与网络配对，请将终端放入一个连接到该网络的 <ItemLink id="wireless_access_point" /> 的右上槽位中。（就是那个带有无线终端图标且下方有箭头的槽位）

它们必须处于 <ItemLink id="wireless_access_point" /> 的范围内才能工作。

它们的能量可以在<ItemLink id="charger" />中充能。

# 无线终端

<ItemImage id="wireless_terminal" scale="4" />

你的基础终端，现在可以便携使用了！在 <ItemLink id="wireless_access_point" /> 的范围内，你可以随时随地查看并访问你的[网络存储](../ae2-mechanics/import-export-storage.md)
中的内容，并从你的[自动合成](../ae2-mechanics/autocrafting.md)系统中请求物品。
