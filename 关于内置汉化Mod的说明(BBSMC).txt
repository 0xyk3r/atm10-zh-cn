关于本汉化包内置修改文件的说明

一、KubeJS 硬编码 Tooltip 汉化脚本

部分模组的物品提示文本（Tooltip）直接写死在 Java 代码中，无法通过语言文件翻译。
本汉化包通过 KubeJS 脚本实现运行时替换，将英文提示替换为中文。

脚本位置：kubejs/client_scripts/
文件命名：{模组ID}_tooltip_zh.js

工作原理：
- 脚本监听 ItemEvents.tooltip 事件
- 遍历物品的 tooltip 行，匹配英文原文
- 将匹配到的行替换为对应的中文翻译

注意事项：
- 需要安装 KubeJS 模组才能生效
- 如果模组更新导致原文变化，可能需要重新生成脚本
- 脚本仅在客户端运行，不影响服务器


二、模组 Data 文件汉化

部分模组的成就（Advancements）、配方书（Recipe Books）、法术书（Spell Tomes）等数据
直接在 JSON 文件中写入英文文本，而非使用语言键引用。

本汉化包提取并翻译了这些硬编码文本，修改后的文件位于：
- data/{模组命名空间}/advancements/  - 成就文件
- data/{模组命名空间}/recipes/       - 配方/法术书等

修改内容：
- 成就的 title（标题）和 description（描述）
- 法术书的 name（名称）和 flavour_text（风味文本）
- 其他包含硬编码文本的数据文件

注意事项：
- 这些文件会覆盖模组原有的数据文件
- 如果模组更新添加了新内容，需要重新生成汉化
- 修改仅涉及文本显示，不影响游戏逻辑


三、技术说明

本汉化包由 BBSMC 自动汉化工具生成，工具会：
1. 扫描模组 JAR 文件中的 Java 类，提取硬编码的 Tooltip 文本
2. 扫描模组数据文件，识别非语言键的硬编码文本
3. 使用 AI 翻译引擎进行翻译
4. 生成 KubeJS 替换脚本和修改后的数据文件

如发现翻译问题或遗漏，欢迎反馈至：https://bbsmc.net
