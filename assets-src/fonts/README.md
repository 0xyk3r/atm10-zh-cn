# 艺术字用的中文字体

`scripts/gen_quest_banners.py` 会**优先**读这个目录里的字体；找不到才退回系统自带的那几款。

## 放什么

按需要的风格放，文件名（不含扩展名）就是脚本里的字体名，`.ttf` / `.otf` / `.ttc` 都行：

| 文件名 | 用途 | 建议字体 | 许可 |
|---|---|---|---|
| `pixel.ttf` | 像素风标题（Mekanism / Powah / 暮色森林 等方块字） | 方舟像素字体 Ark Pixel 12px/16px、Zpix 最像素、缝合像素字体 | OFL / 免费 |
| `serif.ttf` | 粗衬线标题（天境 / 嗡嗡领域 / 自然灵气 / 遗物） | 思源宋体 Heavy、霞鹜文楷、汇文明朝体 | OFL |
| `bold.ttf` | 粗黑标题（机械动力 / 禁忌与奥秘） | 思源黑体 Heavy、得意黑 Smiley Sans | OFL |
| `thin.ttf` | 细体标题（更深更暗 / 动态联合） | 思源黑体 Light | OFL |
| `deco.ttf` | 装饰体（灾变 / 神秘学 这类怪奇风） | 站酷系列、字魂免费商用系列 | 看各自授权 |

## 注意

- 只放**允许再分发**的字体（OFL / 明确免费商用）。本仓库是 GPL-3.0 公开发布的，
  字体文件会随资源包一起分发给玩家，授权不清楚的不要放。
- 放好后直接重跑 `python3 scripts/gen_quest_banners.py` 即可，不用改代码。
- 没放也能跑：脚本会退回系统自带的冬青黑 W3/W6、宋体 SC Black 和 Minecraft 自带的
  Unifont 点阵，只是风格没那么贴原图。
